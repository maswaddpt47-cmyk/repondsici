# repondsici

Adresse courte de **WoocLight** pour les participants : `repondsici.fr/K7M3P`
ouvre l'atelier de code K7M3P sur `wooclight.alwaysdata.net`.

Site statique publié par GitHub Pages depuis `main` (domaine dans `CNAME`).
Aucune donnée, aucun cookie, aucun service tiers : `redirection.js` lit
l'adresse tapée et renvoie vers WoocLight. Test : `node tests/redirection.js`.
